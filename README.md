
# CampusPulse

A campus event management and analytics platform.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL

## Features

- Student management
- Event management
- Event registration
- Attendance tracking
- Analytics dashboard
